# Academic Homepage

[**Homepage**](https://annyab.github.io/)

Personal academic homepage for research, publications, projects, education, and academic experience.

## Usage

- Feel free to borrow this template.
- Update all relevant fields in `_config.yml`, `index.html`, and `assets/`.
- Replace the profile, CV, academic records, publications, project links, and other personal content before deployment.
- The site is deployed through GitHub Pages from the `main` branch.

For local preview:

```bash
bundle install
bundle exec jekyll serve
```
